# 时间的尽头 · THE END OF TIME

一个关于熵、记忆与重生的 Three.js 实时交互作品。

## 最简单的打开方式

双击同目录的 **时间的尽头.html**，使用新版 Chrome 或 Edge 打开即可。

该单文件内嵌了 Three.js、场景代码与样式，无需安装依赖、无需联网、无需开启服务器。已经使用 file:// 在独立 Chrome 测试成功。需要浏览器支持 WebGL 2，建议开启硬件加速。

## 本机网页

交付时生产预览服务运行在：

http://127.0.0.1:5177

这是本机地址，不是公共网址。服务停止后可以运行 `node serve.mjs` 重新打开。

## 玩法

- 鼠标拖动：自由环绕装置。
- 滚轮：靠近或远离。
- 触屏：单指旋转，双指缩放。
- 点击发光菱形：收集五枚记忆，解锁最后的文字。
- 底部时间滑杆：倒流、静止或加速。
- 空格：暂停 / 继续。
- R 或复位按钮：复位镜头和时间流速。
- 让时间重生：触发扩张光波、星尘脉冲，重置记忆，开启新的纪元。
- 右上声音：手动开启/关闭合成环境音与拾取音符。
- 画质按钮：自动 / 高 / 流畅。
- 全屏按钮：在浏览器允许的情况下进入全屏。

## 视觉与实现

- 程序化星云：自定义 GLSL 噪声与多层分形噪声。
- 事件视界：暗核、视角相关的菲涅耳日冕与光子环。
- 吸积盘：极坐标旋涡、噪声扰动、径向条纹着色器。
- 三组破碎天文环：金属 PBR 材质、刻度、轨道与悬浮碎片。
- 星尘：最多 14,000 个 GPU 驱动粒子与 6,500 颗远景恒星。
- 后处理：辉光、轻微色散、径向重生波纹、色调映射。
- 声音：Web Audio 实时生成，无外部音频。
- 碎片与时间：Raycaster 拾取、模拟时间独立控制、确定性程序随机数。
- 可访问性：语义按钮、键盘操作、操作说明、错误提示与减少动态偏好处理。

## 源码开发

已提供 package-lock.json，依赖为项目本地依赖。

```sh
npm ci
npm run dev -- --port 5176
```

生产构建：

```sh
npm run build
node serve.mjs
```

重新生成可双击打开的单文件：

```sh
node package-artwork.mjs
```

## 测试

包含 Playwright 自动化脚本，使用系统已安装的 Chrome 创建隔离测试上下文，不读取日常浏览器登录数据。

```sh
node tests/smoke.mjs
node tests/standalone.mjs
```

smoke 默认测试 http://127.0.0.1:5176；测试生产服务时设置 TEST_URL=http://127.0.0.1:5177。

实际验证：

1. WebGL 初始化和连续渲染。
2. 暂停冻结模拟时间。
3. 负流速倒转时间。
4. 3D 记忆碎片点击拾取。
5. 五枚记忆全部可收集及最终文字。
6. 重生触发并重置记忆。
7. 说明弹窗开关。
8. 画质切换。
9. 环境音开关。
10. 复位镜头及速度。
11. 鼠标拖动旋转镜头。
12. 滚轮缩放。
13. 390px 移动视口无横向溢出。
14. 无 JavaScript / GLSL 编译错误。

以上在开发版、生产版通过；单文件 file:// 运行也通过。

测试截图和报告在 test-results/；源代码包不包含 node_modules 或临时包缓存。
